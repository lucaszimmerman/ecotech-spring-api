# EcoTech API

REST API for EcoTech, a sustainability-focused social network.

## About

EcoTech is a social platform where users can share content about sustainability, interact through comments and likes, and connect with other users.

## Initial features

- User registration and authentication
- User profiles
- Posts
- Comments
- Likes
- Follow

## Technologies

- Java 21
- Spring Boot
- Spring Data JPA
- Spring Security
- PostgreSQL
- Docker
- Maven

## Status

Project under development.
